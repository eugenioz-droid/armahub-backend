# Documentos Fuente Histórica - ArmaHub

Esta carpeta contiene documentos que ya no son programa activo, pero que conservan decisiones
útiles para entender por qué el sistema es como es (trazabilidad).

Diferencia con `superseded/`:

- **superseded/**: documento reemplazado directamente por otro vigente (ej: programa de CODEX → programa reordenado).
- **fuente-historica/**: documento obsoleto como plan, pero con contexto/decisiones que siguen siendo referencia.

Reglas:

- Sus pendientes vigentes ya fueron barridos al programa oficial antes de archivarlos.
- Cada documento lleva una nota al inicio indicando que es fuente histórica y dónde están sus pendientes ahora.
- No usar como programa activo.
- No mover ni borrar sin confirmación del usuario.
