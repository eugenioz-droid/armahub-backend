# Documentos Superseded - ArmaHub

Esta carpeta queda reservada para documentos reemplazados por el protocolo o programa vigente.

Reglas:

- Mover aqui solo documentos que ya no sean fuente operativa.
- Mantener el nombre original del archivo cuando sea posible.
- Agregar una nota al inicio del documento movido indicando por que fue reemplazado.
- No mover ni borrar documentos sin confirmacion del usuario.
